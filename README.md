## Acerca de este repositorio

Este repositorio contiene actividades, prácticas y proyectos desarrollados de forma colaborativa durante el curso **Arquitectura de Computadores y Ensambladores 1**.

Su propósito es reunir y organizar de forma estructurada los trabajos realizados por el grupo durante el semestre, facilitando el acceso a cada actividad, práctica o proyecto y a los recursos utilizados para su desarrollo.
